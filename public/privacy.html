1. Introduction and Scope

This Privacy Policy governs the mobile application "Світло в Житомирі" (package name com.ZTBlackoutPreWarning), created and maintained by Igor Zaharov as a free, open-source utility.

The Application is designed to provide residents and organizations in the Zhytomyr region of Ukraine with timely, accurate information regarding scheduled electrical power outages published by JSC "Zhytomyroblenergo" (АТ «Житомиробленерго»).

We are strictly committed to user privacy. This document outlines our data handling practices in accordance with the Google Play Developer Program Policies, the General Data Protection Regulation (GDPR) (EU) 2016/679, and the Law of Ukraine "On Protection of Personal Data" (Закон України «Про захист персональних даних» № 2297-VI).

2. Principle of Zero Data Collection (Data Minimization)

  • No Personal Data Collected: The Application does not collect, solicit, aggregate, record, store, sell, lease, or monetize any Personally Identifiable Information (PII).
  • No User Accounts: There is no registration, login, profile creation, or authentication required to use the Application.
  • No Advertising or Behavioral Profiling: The Application contains no advertising frameworks, ad-tracking SDKs, or commercial behavioral profiling mechanisms. It does not access the Android Advertising ID (AAID).
  • No Analytics or Telemetry: The Application does not integrate third-party analytics services (e.g., Google Analytics, Firebase SDK, AppsFlyer, Facebook SDK). We do not collect telemetry, diagnostic crash reports containing device IDs, or usage statistics.
  • No Location Tracking: The Application does not request or access GPS, coarse location, Wi-Fi SSID information, or cellular network data.

3. Information Processed Locally on the User's Device

All configuration settings and operational data created during application use are retained strictly on the user's physical device within the sandboxed Android application private storage (SharedPreferences under Context.MODE_PRIVATE). This information is never transmitted to any external server or third party.

  • Selected Power Outage Queue: The user's chosen consumer sub-queue (e.g., queues 1.1 through 6.2).
  • Notification & Pre-Warning Settings: The user's chosen pre-warning lead time (e.g., 15 or 30 minutes in advance), sound toggles, and vibration toggles.
  • Audio Preferences: Sound effects and music volume sliders.
  • Offline Cache: Cached electricity outage schedule tables to enable offline viewing when network access is unavailable.
  • Mini-Game State ("Житомирська Рулетка"): Local game scores, achievements, daily streak counters, and mini-game power points.

4. Network Connections and Data Sources

The Application requires internet access exclusively to fetch publicly accessible data necessary for its primary utility function:

  • JSC "Zhytomyroblenergo" Schedule Server: (https://www.ztoe.com.ua/unhooking-search.php) — Retrieving publicly published hourly power outage schedule HTML tables. No user credentials, cookies, device identifiers, or personal parameters are sent.
  • Static Configuration File (GitHub Raw): (https://raw.githubusercontent.com/IgorZaharov/Android-ZTBlackoutPreWarning/main/donations.json) — Periodically retrieving optional community donation URLs and official information links using standard conditional HTTP headers (ETag / If-Modified-Since).

5. Android Device Permissions and Technical Justification

Permission Technical Requirement & Justification
android.permission.INTERNET Required to communicate via HTTPS with the public servers of JSC "Zhytomyroblenergo" and retrieve blackout schedules.
android.permission.ACCESS_NETWORK_STATE Required to verify whether an active Wi-Fi or cellular network connection is available prior to initiating network queries.
android.permission.POST_NOTIFICATIONS Required on Android 13+ (API 33+) to present local notifications warning the user of imminent electrical outages according to their configured preference.
android.permission.SCHEDULE_EXACT_ALARM
android.permission.USE_EXACT_ALARM		 Required to schedule exact, time-critical local alarms using Android AlarmManager so pre-warnings trigger at the precise minute chosen by the user even in Doze mode.
android.permission.RECEIVE_BOOT_COMPLETED Required to automatically restore and reschedule the user's configured local outage warning alarms following a device reboot or system time adjustment.
android.permission.VIBRATE Required to deliver haptic vibration feedback alongside notifications if enabled in the user's settings.
android.permission.WAKE_LOCK Required momentarily during exact alarm broadcasts to guarantee that the notification dispatch routine completes successfully before the device returns to sleep.

6. Third-Party Links and External Services

The Application contains hyperlinks to external third-party platforms (e.g., JSC "Zhytomyroblenergo" website, official Facebook page, Monobank voluntary donation jar, and GitHub repository). We do not control or assume responsibility for external privacy practices.

7. Children's Privacy (COPPA & GDPR Compliance)

The Application does not target, knowingly interact with, or collect information from children under the age of 13 (or under 16 within the European Economic Area). Because the Application collects no personal data whatsoever, it is fully compliant with COPPA and Google Play Families Policy.

8. Data Storage, Security, and Retention

All settings are stored exclusively in the private sandboxed storage on the user's device. Users retain 100% control over their data and can clear all data at any time via Android Settings (Settings > Apps > Світло в Житомирі > Storage > Clear Data) or by uninstalling the Application.

Ця Політика регулює використання додатку «Світло в Житомирі». Додаток не збирає, не реєструє, не передає та не продає персональні дані користувачів. Реєстрація відсутня. Трекінгові або рекламні модулі відсутні.

2. Локальне збереження

Усі налаштування (номер черги, час нагадування, налаштування звуку) зберігаються виключно на вашому телефоні (у SharedPreferences) і нікуди не передаються.

3. Дозволи Android

Дозволи використовуються виключно для технічного функціонування (завантаження графіка з сайту ztoe.com.ua, надсилання локальних сповіщень та точний таймер попередження).

4. Видалення даних

Користувач може будь-коли стерти всі налаштування через «Налаштування > Програми > Світло в Житомирі > Очистити дані» або просто видаливши додаток.
