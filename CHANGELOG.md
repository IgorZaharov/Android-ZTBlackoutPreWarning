# Changelog

## [1.1.0] - 2026-10-31

### Added
- **Valid Site URLs Registry (`/valid-urls.json`)**: Added repository configuration file `/valid-urls.json` (and synced copies in `public/valid-urls.json` and `android/app/src/main/assets/valid-urls.json`) containing `["https://www.ztoe.com.ua/unhooking-search.php", "https://example.com"]` for strict URL verification.
- **Donations Block in About Window (`/donations.json`, `AboutScreen.kt`, `AboutView.tsx`, `DonationsRepository.kt`, `donationsService.ts`, `AppStrings.kt`, `i18n.ts`)**: Added `"Donations / Благодійність і Пожертви"` block after `"Посилання на проект"` in the About window, styled identically to project links. Reads donation links from `/donations.json` on GitHub (`https://raw.githubusercontent.com/IgorZaharov/Android-ZTBlackoutPreWarning/main/donations.json`) and re-reads 1 time per day (24h cache), with defaults `Допомога тваринам - https://send.monobank.ua/jar/7vJA5xrLoV` and `Фонд Повернись Живим - https://savelife.in.ua/donate/`.
- **Gradual Time-of-Day Blurred Background (`TimeOfDayPalette.kt`, `timeOfDayPalette.ts`, `BlackoutAppNavigation.kt`, `PhoneSimulator.tsx`, `App.tsx`)**: Added dynamic time-of-day background color interpolation across Morning (`#F4F9F9`, `#4A7C59`, `#FFB085`, `#2C3E35`), Day (`#FFFFFF`, `#0A2540`, `#FFD166`, `#4682B4`), Evening (`#1A0B2E`, `#8B3A62`, `#FF6B6B`, `#FFE66D`), and Night (`#0B0C10`, `#1F2833`, `#66FCF1`, `#C5C6C7`) with 60% Primary, 30% Secondary, and 10% Accent distribution, plus interactive preview buttons (`Авто`, `Ранок`, `День`, `Вечір`, `Ніч`) in the Emulator Test Workbench (`App.tsx`).
- **Widget Round Refresh Button**: Added a round Refresh button (`ic_refresh.xml` / `RefreshCw`) on both Small (2x1) and Big (3x2/4x2) widgets (`BlackoutGlanceWidget.kt`, `WidgetSimulator.tsx`) matching the Notification toggle button style. Pressing it reads the selected queue from Settings, fetches live schedule data from the website, and refreshes widget contents.
- **Emergency Outages Link on Main Window**: Added link `Інформація про аварійні відключення: https://www.facebook.com/ztoe.com.ua` (`Emergency outages info: https://www.facebook.com/ztoe.com.ua`) at the bottom of the Main Window right after the refresh block, styled like the links in the About Window with the Facebook logo icon and word wrapping (`MainScreen.kt`, `MainView.tsx`, `AppStrings.kt`, `i18n.ts`).
- **Immediate Widget Data Fetch on Add**: Both Small (2x1) and Big (3x2/4x2) widgets now immediately load the selected queue and fetch live blackout schedule data as soon as they are added to the home screen without requiring manual refresh (`BlackoutWidgetReceiver.kt`, `BlackoutGlanceWidget.kt`, `ScheduleRepository.kt`).
- **Automated CI/CD Unit Tests (`tests/unit.test.ts`, `ZtoeParserTest.kt`, `.github/workflows/build-apk.yml`)**:
  - **Unit Test A**: Verifies live/fixture HTML parsing from `https://www.ztoe.com.ua/unhooking-search.php` for a randomly selected queue (`1.1`–`6.2`), determines blackout timeslots for Today, and asserts 100% parity between the 24h half-hour graph blocks in the Main Window and Big Widget.
  - **Unit Test B**: Verifies critical UI invariants (application name, icons, labels, default timer values, help popup text, widget status text, error messages, emergency link, donations block, and time-of-day background palettes) and ensures any UI file modifications are documented in `CHANGELOG.md`.

### Changed
- **Application Name**: Changed application name to `"Світло в Житомирі"` across Android (`strings.xml`, `AppStrings.kt`, `androidProjectFiles.ts`) and Web (`metadata.json`, `index.html`, `i18n.ts`, `App.tsx`, `PhoneSimulator.tsx`).
- **Default Timer Constants (Critical)**: Set default Advance Warning (`advanceNoticeMinutes`) to `15` minutes and Site Refresh Interval (`refreshIntervalMinutes`) to `30` minutes across Android (`Models.kt`, `SettingsRepository.kt`, `AppStrings.kt`, `SettingsScreen.kt`) and Web (`types.ts`, `App.tsx`, `SettingsView.tsx`, `i18n.ts`). Marked as critical constants.
- **Settings "?" Queue Help Popup Text (Critical)**: Reverted help dialog instructions in Settings (`AppStrings.kt`, `SettingsScreen.kt`, `i18n.ts`, `SettingsView.tsx`) to the exact 4-step numbered list with `"Зрозуміло"` / `"Got it"` confirmation button and marked as critical.
- **Master Notification Toggle State Memory**: Turning off the master Notification toggle now saves the current states of Sound and Vibration (`prevSoundEnabled`, `prevVibrationEnabled`), turns both off, and disables their switches. Turning the master Notification toggle back on restores Sound and Vibration to their previous states (`Models.kt`, `SettingsRepository.kt`, `SettingsScreen.kt`, `types.ts`, `App.tsx`, `SettingsView.tsx`).
- **Widget Status Labels**: Updated widget status labels to `"СВІТЛО Є"` / `"СВІТЛА НЕМАЄ"` (`BlackoutGlanceWidget.kt`, `WidgetSimulator.tsx`, `androidProjectFiles.ts`).
- **Emulator 24h Time Graph Color Scheme (`MainView.tsx`, `WidgetSimulator.tsx`)**: Kept the outer schedule card and outage intervals list in dark frosted glass while styling the inner 24h timeline graph and needle after the classic analog electricity meter (`САЗУ-ИТ`) palette: warm vintage enamel beige faceplate (`#DFDDD0`–`#C6C2B0`), recessed metallic counter drum slot (`#4E514E`), 1.5px light gray (`#C8C6BC`) hour separators with no half-hour separators, cylindrical white power-on drum blocks, crimson red (`#D62E26`) blackout drum blocks, black (`#0B0B0A`) current time needle protruding 4px above and below the dark-grey contour, and stamped black ink (`#1C1B18`) hour tick markers.

### Fixed
- **Vibration When Sound Is Disabled**: Fixed notification channel and hardware vibration logic so vibration triggers reliably when `vibrationEnabled = true` and `soundEnabled = false` (`NotificationHelper.kt`, `alertManager.ts`, `App.tsx`).
- **Widget Notification Toggle Sync**: Fixed notification toggle button on both Small (2x1) and Big (3x2/4x2) widgets using `PreferencesGlanceStateDefinition` and `ColorFilter.tint` so state updates immediately and stays synchronized across Main Window, Settings, and Widgets (`BlackoutGlanceWidget.kt`, `WidgetToggleReceiver.kt`, `WidgetSimulator.tsx`).
- **Live ZTOE HTML Schedule Parser (Critical)**: Fixed `ZtoeParser.kt` and `ztoeParser.ts` to filter leaf `<table>` elements (`table.select("table").isEmpty()`), decode `windows-1251` Cyrillic text, and match `DD.MM.YYYY` date headers in `Europe/Kyiv` timezone for Today and Tomorrow. Today button loads Today's schedule into Main Window and Widget; Tomorrow button appears only when tomorrow's date table exists on the site; Widget always displays Today's schedule. Marked parser code as critical.
- **URL Verification & Refresh Error Reporting**: Refresh button and URL verification now validate against `/valid-urls.json`, verify internet connectivity, and confirm a schedule table with the current date and queues exists. Reports `"Немає доступу до Інтернету"` (`"No Internet access"`) when offline and `"На сайті не знайдено черг"` (`"No queues found on site"`) when no valid queue table is found (`ZtoeParser.kt`, `ztoeParser.ts`, `AppStrings.kt`, `i18n.ts`, `BlackoutAppNavigation.kt`, `SettingsScreen.kt`, `App.tsx`, `SettingsView.tsx`).
- **App Icon in Settings Refresh Notification & Adaptive Icon**: Replaced raw OS `Toast` on Settings/Main Refresh with a custom in-app notification banner displaying the app lightning icon (`BlackoutAppNavigation.kt`, `SettingsScreen.kt`), added `<monochrome>` layer to `ic_launcher.xml` and `ic_launcher_round.xml`, and generated density PNG launcher icons (`mipmap-mdpi` through `mipmap-xxxhdpi`) so the standard Android robot icon never appears.
- **ViewPager Swipe Jitter**: Set `beyondViewportPageCount = 2` on `HorizontalPager` and hoisted repository allocations out of per-frame composition to eliminate jitter when swiping between screens (`BlackoutAppNavigation.kt`).
- **Memory Leaks, Cache Preservation & Background Battery Drain**: Switched repositories (`SettingsRepository.kt`, `ScheduleRepository.kt`, `AlertRegistry.kt`) to `context.applicationContext`, pruned stale notification records in `AlertRegistry.kt`, closed `HttpURLConnection` in `finally` blocks (`ZtoeParser.kt`, `DonationsRepository.kt`), preserved valid today schedule cache during transient network drops (`ScheduleSyncWorker.kt`, `BlackoutWidgetReceiver.kt`, `BlackoutGlanceWidget.kt`, `BlackoutAppNavigation.kt`), gated the status dot `InfiniteTransition` on `isBlackoutNow` (`MainScreen.kt`), keyed time-of-day background palette recomputation to once per minute (`BlackoutAppNavigation.kt`), unregistered `SharedPreferences` listeners inside `DisposableEffect`, closed Web `AudioContext` after playback (`alertManager.ts`), gated the 1-second UI countdown loop on `Lifecycle.State.RESUMED`, and synchronized `ScheduleSyncWorker` (`BootCompletedReceiver.kt`, `BlackoutAppNavigation.kt`) with `NetworkType.CONNECTED` and `settings.refreshIntervalMinutes` (30m default).
